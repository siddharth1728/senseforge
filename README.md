# ✨ A Diwali Made of Light — For Bangarammm ❤️

> A bespoke, luxury cinematic Diwali interactive storytelling experience crafted exclusively for **Bangarammm**.

---

## 🌟 The Experience Journey

1. **Scene 1 — The Mysterious Opening**
   - Deep cinematic midnight darkness.
   - Central realistic handcrafted Diya gently flickering with ambient golden illumination.
   - Floating golden dust particles.
   - Poetic prelude: *"Some lights make a festival beautiful... Some people make life beautiful. Tonight, this little celebration is for you."*
   - Interactive surprise reveal button with golden light sweep.

2. **Scene 2 — The Grand Diwali Reveal**
   - Breathtaking festive composition with deep burgundy and royal wine gradients.
   - Visual centerpiece: **"Bangarammm ❤️"** in champagne gold display typography with radiant glow.
   - Supported by: *"May your world always shine brighter than a thousand diyas."*
   - Traditional marigold festoons and flanking glowing diyas.

3. **Scene 3 — The Interactive Diya Experience**
   - 5 interactive sacred diyas representing:
     1. **Happiness** (*"May your smile never lose its magic."*)
     2. **Peace** (*"May your heart always find its beautiful moments of peace."*)
     3. **Success** (*"May every dream you hold find its way into reality."*)
     4. **Beautiful Memories** (*"May life surprise you with countless moments worth remembering."*)
     5. **Endless Love** (*"May you always be surrounded by warmth, kindness, and love."*)
   - Each touch ignites a realistic flame, spreads a warm golden halo, and plays a sacred bell chime.
   - Lighting all 5 unlocks celebratory golden confetti and reveals: *"Look at that... you just made this little world brighter. ❤️"*

4. **Scene 4 — The Personalized Love Letter**
   - Elegant digital envelope in deep burgundy with champagne-gold borders.
   - 3D wax seal with heart imprint that unseals with an acoustic harp flourish.
   - Warm ivory parchment letter unfolds smoothly with intimate message crafted specially for Bangarammm.

5. **Scene 5 — The Wishes for Her**
   - Visually warm and lighter atmosphere.
   - Staggered presentation of five blessings with golden emblems.

6. **Scene 6 — The Grand Finale**
   - Night sky with dynamic fireworks canvas.
   - Trio of celebratory glowing diyas.
   - Final message: *"Keep shining. Keep smiling. Keep being you. Some celebrations last a night. Some beautiful feelings stay forever."*
   - Delicate golden heart motif.
   - Replay button: *"Experience the magic again ↗"* that restarts the journey.

## 🎵 Sound Design

- Built using the native **Web Audio API** (100% offline, zero network dependencies, no broken links).
- Atmospheric drone chord in D Major / Raga Bhupali with resonant low-pass filter breathing.
- Individual chime sounds on diya kindling and envelope unsealing.
- **Never autoplays** — user controlled with an elegant glass-pill toggle featuring live animated equalizer soundwaves.

## 🚀 Local Run Instructions

1. Clone or navigate to the repository directory:
   ```bash
   cd c:\akshar
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` (or the indicated port) in any mobile or desktop browser.

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Deployment Instructions (Shareable Public Link)

### Option A: Deploy to Vercel (Recommended, 1-Click)
1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: A Diwali Made of Light for Bangarammm"
   git push origin main
   ```
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Framework preset: **Vite**.
4. Click **Deploy**. Vercel will instantly provide a custom HTTPS URL to share directly with her!

### Option B: Deploy via Netlify
1. Run `npm run build` to generate the `dist` folder.
2. Drag and drop the `dist` folder into [Netlify Drop](https://app.netlify.com/drop) or connect your GitHub repository.
